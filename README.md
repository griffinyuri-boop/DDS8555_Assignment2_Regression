# DDS8555 Assignment 2 – Regression Models

This repository contains the Python notebook used for Assignment 2 in DDS8555.

The notebook builds regression models using the Carseats dataset and the Abalone dataset from Kaggle.

Models included:
- Linear Regression
- Random Forest Regression

The models were submitted to the Kaggle "Regression with Abalone Dataset" competition for evaluation.
